# Velcro Underground

**Tech House / After Hours**

A tech house project built on rooms nobody advertises — the ones you find out about the night before. Rolling low-end, hypnotic groove, and just the right amount of grit.

## About

Velcro Underground is a sonic experience. Every set is built to hold a room from first record to sunrise, whether that room holds forty people or four thousand.

- **Based**: Underground, Everywhere
- **Sound**: Psych House / Groove
- **Sets Played**: 30
- **Avg Set Length**: 3 Hours
